What this is / is not

This dashboard talks directly to the live API deployed on Vercel using your browser's own network connection (not a server-side proxy), authenticated with the bearer token above. Everything you see here — account balance, ticks, orders — is generated by a mock/simulated gateway seeded with synthetic data, exactly as configured by gateway_mode: mock and account_mode: demo at the top of the API. Before this could ever be pointed at a real broker account it would still need, at minimum: a real MT5/broker gateway integration running on a VPS with a persistent connection, a managed Postgres database (the current one resets on redeploy), re-validation of every strategy against fresh out-of-sample data (the trend-following strategy currently on record scored an out-of-sample Sharpe of ~0.05, well under the 0.3 promotion floor enforced by /models/{'{'}version{'}'}/promote), and a deliberate human decision to move account_mode off "demo". None of that has been done here, and this tool will keep saying so rather than implying otherwise.
