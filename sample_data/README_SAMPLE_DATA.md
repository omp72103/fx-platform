# This data is SYNTHETIC

`EURUSD_sample.csv` is a randomly generated series (seeded random walk with
deliberate trend/volatility segments), NOT real EURUSD prices. It exists
only so `scripts/run_paper_loop.py` and `app/backtest/engine.py` have
something to run against immediately, with zero setup.

Generated by (see also `tests/conftest.py`'s `synthetic_ohlc` fixture, which
builds the same shape of data for the test suite):

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(7)
n = 900
seg1 = rng.normal(0, 3, 300)                       # choppy range
seg2 = np.full(300, 8) + rng.normal(0, 4, 300)      # steady uptrend
seg3 = rng.normal(0, 40, 150)                       # high-volatility chop
seg4 = np.full(150, -8) + rng.normal(0, 4, 150)     # downtrend
...
```

**Do not draw any conclusion about a strategy's real-world viability from a
backtest run against this file.** Point `HISTORICAL_CSV_PATH` in `.env` at a
real historical export (the ejtraderLabs EURUSD_d1.csv referenced in the
original `data_pipeline_ohlc.py`, an MT5 export, or the Federal Reserve H.10
series used in `Forex_Strategy_Backtest_Explained.pdf`) before trusting any
number that comes out of `app/backtest/engine.py`.
